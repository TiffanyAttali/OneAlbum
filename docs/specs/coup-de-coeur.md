# Spec: Coup de cœur

Draft v0.1, 2026-10-13. For Tiff's review. Rules it touches: Identity (ratings never steer picks).

## What the user sees
- A heart button next to the stars on the album screen and in the "How did it land?" sheet: **Coup de cœur**.
- One tap = on, tap again = off. Works offline.
- A **"Coups de cœur"** shelf in the history: the albums the user fell for, newest first, with the cover and a one-line note.
- A coup de cœur can be added later from the history, not only right after listening.

## How it counts
- Stored on the device with the rating (no account, nothing sent anywhere).
- It's the strongest quality cue: an album with a coup de cœur tells the picker "this kind of risk paid off".
- It never pulls the next picks toward similar albums (loved albums create loops). It can raise how far out the
  picker dares to go, the same way 5/5 ratings do today, with the same cap and fading weight.
- Implies at least 4/5 if no stars were given.

## Later, optional
